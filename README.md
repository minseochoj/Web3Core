# Web3Core

Web3Core is a decentralized platform enabling real-time transaction processing and auto-scaling for high-throughput node networks.

The key benefits of using Web3Core include:

- Web3Core is a decentralized platform
- enabling real-time transaction processing and
- auto-scaling for high-throughput node networks

## Key Features

- Web3Core is a decentralized platform

- auto-scaling for high-throughput node networks

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3Core.git`
2. `cd Web3Core`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Core, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
